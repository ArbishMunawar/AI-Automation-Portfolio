# 🚀 Day 11 – AI Resume Analyzer with Automated Candidate Screening

An AI-powered Resume Analyzer built using **n8n**, **Google Gemini**, and **MySQL** that automates candidate screening, resume evaluation, database storage, and personalized email responses.

## 📌 Project Overview

Recruiters spend hours manually reviewing resumes. This workflow automates the entire screening process by:

- Extracting resume content
- Analyzing candidate qualifications using AI
- Assigning a suitability score (0–100)
- Storing candidate details in MySQL
- Automatically sending interview invitations to shortlisted candidates
- Sending personalized improvement emails to rejected candidates
- Updating candidate status in the database

## 📧 Email Automation

### 🎉 Score ≥ 80

The candidate automatically receives:

- Interview Invitation
- Congratulations email
- Next hiring steps

Database Status:

```
Interview Invited
```

---

### ❌ Score < 80

The candidate automatically receives:

- Polite rejection email
- Personalized improvement suggestions generated by AI
- Encouragement for future opportunities

Database Status:

```
Rejected
```
